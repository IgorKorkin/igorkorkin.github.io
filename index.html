AboutОбо мне

I am an operating-system security researcher and a PhD in information security, with a background in Windows internals, kernel protection, hardware-assisted virtualization, and memory forensics. My work combines low-level system programming with experimental security research and practical defensive mechanisms.

I graduated from Department No. 42 at National Research Nuclear University MEPhI in Moscow. My professional experience includes cybersecurity research projects at Huawei Technologies and Binarly. I have presented research at Black Hat, HITB, LABScon, and other international conferences, and supervise student research in information security at MEPhI.

Selected Research

My research focuses on operating-system isolation and defense mechanisms, from hardware-assisted kernel protection to Windows GUI security and constrained execution of autonomous software agents. The projects below connect ideas, implementations, publications, and conference presentations.

Windows Desktop & GUI Security

DesktopRanger

Isolation of Windows Desktop objects to reduce cross-desktop access, GUI-hook exposure, and interception of user interaction. Current experiments include desktop access policies and detection using decoy Desktop objects.

Source code · Research notes

Hypervisor-based Kernel Protection

MemoryRanger

Hardware-assisted memory isolation for Windows kernel components using Intel virtualization technology and Extended Page Tables. The project investigates ways to restrict unauthorized memory access by kernel-mode code.

Source code · Black Hat Europe 2018

Autonomous AI Agent Isolation

ZIS — Protected Interactive Environment

Ongoing research on operating-system mechanisms for executing autonomous AI agents with constrained access to files, processes, network resources, and interactive Windows objects.

Related isolation research

Endpoint Telemetry & Evasion

ETW & WMI Security

Research into attacks and trust boundaries in Windows Event Tracing (ETW) and Windows Management Instrumentation (WMI), including their implications for EDR and SIEM visibility.

Black Hat Europe 2021 · Black Hat USA 2022
